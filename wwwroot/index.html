Versiones y asignación

Arma el adiestramiento una vez con todo el contenido. Luego crea sets (versiones) donde solo eliges qué se enseña — todo viene marcado y desmarcas lo que no quieres. Al usuario siempre le aparece el mismo nombre del adiestramiento. Asigna qué set ve cada usuario o cohorte. Precedencia: usuario › cohorte › set por defecto.
